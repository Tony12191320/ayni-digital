**Proyecto académico – Universidad Continental**

## Descripción
AYNI Digital es una página web educativa dirigida a pequeños emprendedores de Cusco. Su objetivo es ofrecer herramientas y recursos gratuitos para mejorar la presentación de productos y la organización de pedidos.

## Funcionalidades
- Navegación entre las secciones de la página.
- Ruta digital de tres pasos para emprendedores.
- Guía práctica descargable en PDF.
- Formulario de contacto.
- Diseño adaptable a distintos dispositivos.

## Herramientas utilizadas
- WordPress
- Elementor
- Forminator
- InfinityFree
- GitHub
